# Privacy Policy — «Вопрос на ночь» autopost

Last updated: 19 November 2026

This is a private tool used only by the owner of the «Вопрос на ночь» channel to upload the channel's own videos to the owner's own TikTok and VK accounts.

**What data is used.** When the owner signs in, the app receives an access token and basic profile information (account ID, display name) from TikTok or VK. It uses them only to upload videos and check upload status on the owner's own account.

**What is not done.** No data of other users is collected. Nothing is sold, shared with third parties, or used for advertising or analytics.

**Storage.** Tokens are stored in a private file accessible only to the owner and are deleted when the owner revokes access.

**Revoking access.** Access can be revoked at any time in TikTok or VK account settings (connected apps).

**Contact.** Through the GitHub profile of the repository owner: https://github.com/14mila88-ux
